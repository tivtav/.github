# tivtav/.github

Organization-wide defaults for all [tivtav](https://github.com/tivtav) repositories. 🦷

Any repository without its own version of these files automatically falls back to the ones here.

## 📂 What's inside

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Public organization profile shown on [github.com/tivtav](https://github.com/tivtav) |
| [`SECURITY.md`](SECURITY.md) | How to privately report security vulnerabilities |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug report and feature request forms, plus support links |
| [`pull_request_template.md`](pull_request_template.md) | Default pull request description and checklist |

## ✏️ Making changes

Changes here affect every repository in the organization, so open a pull request and get a review before merging.

Learn more about [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
